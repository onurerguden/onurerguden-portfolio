# The Explorer on phones (review 06)

`explorer-en-375.webp` and `explorer-tr-375.webp` show the Explorer at 375 × 812, left to right: before, after (first three technologies of each group, then "Show all 48" / "Tümünü göster (48)"), and after opening it ("Show fewer" / "Daha az göster"). The page's fixed bar is hidden for the capture only.

| | Height at 375 × 812 |
|---|---|
| Before | 3,184 px (3.9 screens) |
| After, closed | 1,172 px (1.4 screens) |
| After, open | 3,244 px |

Wider screens and the desk's own Explorer window are unchanged, and without JavaScript the list stays complete. The button has `aria-expanded` and `aria-controls`, keeps its focus when it changes its label, and stays in view after closing.
