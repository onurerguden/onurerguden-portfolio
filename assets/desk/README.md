# Onur's desk source

Original model authored for Onur Ergüden from his supplied setup photographs. Photos are local reference only and are not embedded or redistributed. Source screen contents are excluded. The clean wide photo controls arrangement; September 6 close-ups control riser/drawer, Lenovo foot, Xiaomi clamp/dial, laptop keyboard and headphone/lamp details.

## Rebuild

Use Node 24 and Blender **4.5.13 LTS**. On this machine Blender is installed in `/Users/onurerguden/Applications/Blender.app`.

```sh
/Users/onurerguden/Applications/Blender.app/Contents/MacOS/Blender --background --python scripts/desk/build.py -- --render
npm run desk:package
npm run test -- tests/desk-model.test.ts
```

The script overwrites only its generated model, camera contract, report and rendered previews. `onur-desk.blend` retains individually named editable geometry, packed authored textures, lights and a review camera. The delivery GLB batches geometry by material and retains named screen anchors. `artifacts.json` records outputs by hash; re-rendering may change byte hashes across graphics drivers or Blender versions.

Official macOS ARM64 installer: https://download.blender.org/release/Blender4.5/blender-4.5.13-macos-arm64.dmg

Verified against the official `blender-4.5.13.sha256`: `663ce944257c61ff1d6aa09e15c8f57bbd8d59023adb2fa7edde33a9ed960b53`.

## Scale and approximation

Metres in Blender (Z up), glTF and camera contract (Y up). Desk dimensions are user-confirmed 1.50 × 0.80 m. Samsung 24-inch portrait, Lenovo 29-inch ultrawide, Xiaomi lightbar, MacBook Pro 14 M1 Pro, Razer Barracuda and MX Master 3S are user-identified. Monitor product numbers and IKEA stand SKU were not supplied: housings, feet and accessory dimensions are photo-derived approximations, not manufacturer CAD. Display ratios default to 16:9 rotated and 21:9; MacBook housing is based on the identified 14-inch generation.

The IKEA metal riser is separate from the Lenovo silver base. Its top, drawer and sides use an original repeating mesh texture, not thousands of wires. Keyboard legends, device silhouettes, lightbar clamp, both mouse wheels and two rests are geometric. Tablet is decorative and is not a fourth journey stop. Lamp color is a fixed pale rose, with warm left light and monitor light. Wall is a presentation backdrop; unseen room furniture is omitted.

All textures are generated by the script (128 px, packed in GLB). No externally licensed device model, image or HDRI is used. Draco decoder is an unchanged, separately licensed dependency in `public/decoders/draco`.
